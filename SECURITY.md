# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull requests. If private vulnerability reporting is enabled for this repository, use the repository's **Security** tab to submit a report. Otherwise, contact the repository maintainers privately through GitHub.

Include the affected component, the potential impact, and steps to reproduce the issue when it is safe to do so. Please allow maintainers reasonable time to investigate and coordinate a fix before sharing details publicly.

## Scope

Reports about this repository's code and supported workflows are in scope. This policy does not promise a particular response time or security advisory process.
