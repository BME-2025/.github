# Support

For questions about using this project or for help with a reproducible problem:

- Check the README and existing issues first.
- Open a GitHub issue with a clear title, the steps you took, what you expected, and what happened.
- Include relevant environment details, such as Python version and operating system. Remove credentials, private data, and other sensitive information before posting.

Use the bug report template for suspected defects. Do not use public issues for security vulnerabilities; follow the instructions in [SECURITY.md](SECURITY.md).
